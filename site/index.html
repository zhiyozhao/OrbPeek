OrbPeek

把 Mac 上的窗口贴到屏幕边上，鼠标移过去，它就滑出来。

安装 ↓

安装

需要 macOS 14 或更高版本，免费开源。

  1. 用 Homebrew 安装

    brew install --cask zhiyozhao/tap/orbpeek

    在「终端」里运行这一行。

  2. 打开 OrbPeek

    在「应用程序」或聚焦搜索里打开。它只在菜单栏显示一个图标，没有 Dock 图标。

  3. 允许「辅助功能」

    按提示进入「系统设置 → 隐私与安全性 → 辅助功能」，打开 OrbPeek 的开关。打开后马上可以用。

  4. 允许「屏幕录制」可选

    点菜单栏里的 OrbPeek 图标，选「屏幕录制 — 点击授权」。预览条的画面和滑动效果要用到它；不允许也能贴边，只是预览条是一条深色的空条。

不用 Homebrew：下载 DMG，把 OrbPeek 拖进「应用程序」。第一次打开会被系统拦下，处理方法见 README。

用法

⌃⇧←→↑↓
把最前面的窗口贴到左、右、上、下边。按另一个方向键，就换一条边。
鼠标移到预览条上
窗口滑出来，可以直接用。鼠标移开，或者切到别的 app，它就滑回去。
沿着边拖动
窗口滑出来时拖动它，松手后预览条停在新位置。
放回桌面
在菜单栏图标里点这个窗口的名字。退出 OrbPeek 时，所有窗口都会放回原处。

快捷键、预览条宽度和不透明度可以在菜单栏图标的「设置…」里改。OrbPeek 不联网，没有账号和统计。
