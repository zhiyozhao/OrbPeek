用 Homebrew 安装

推荐
  1. 打开「终端」，运行：
    brew install --cask zhiyozhao/tap/orbpeek
  2. 在「应用程序」里打开 OrbPeek。图标会出现在菜单栏，没有 Dock 图标。
  3. 按下面的说明，开启窗口控制和预览权限。

Homebrew 安装后可直接打开，不需要处理开发者验证。
以后更新：brew upgrade --cask orbpeek，更新后重新打开 OrbPeek。

手动安装

DMG
  1. 下载最新的 OrbPeek-版本号.dmg。
    下载 DMG ↗
  2. 打开 DMG，把 OrbPeek 拖进「应用程序」，再从那里打开。
  3. 首次打开若提示无法验证开发者，按下方说明允许打开，再开启权限。
提示「无法验证开发者」怎么办？

OrbPeek 尚未经过 Apple 公证。先尝试打开一次，再进入「系统设置 → 隐私与安全性」，在底部找到 OrbPeek 的提示，点「仍要打开」，按系统提示验证后确认打开。macOS 14 也可以在「访达」中按住 Control 点 OrbPeek，选「打开」，再确认一次。

第一次打开，设置两项权限。

两种安装方式都需要。入口都在「系统设置 → 隐私与安全性」。

辅助功能必需 · 用来移动窗口

首次打开会提示。点「打开设置」，开启 OrbPeek；如果列表里没有，点「+」添加「应用程序」中的 OrbPeek。授权后即可使用，不需要重启。不开启就无法贴边或呼出窗口。

隐私与安全性 → 辅助功能 → OrbPeek

屏幕录制可选 · 让预览条有画面

点菜单栏 OrbPeek 图标，选「屏幕录制 — 点击授权」，阅读说明后点「继续」，再按系统提示允许。不授权也能贴边和呼出，只是边上会显示深色占位条。若系统要求退出并重新打开，请按提示操作。

隐私与安全性 → 屏幕录制
部分系统显示为「屏幕与系统音频录制」

MAKE IT YOUR SPACE

贴上去。
需要时，再回来。

  1. 选中一个窗口，按 {{DEFAULT_MODIFIERS}}← / → / ↑ / ↓，贴到对应的屏幕边缘。
  2. 鼠标移到预览条上，窗口就出现；移开，窗口就收起。
  3. 点菜单栏图标 →「设置…」，可以改快捷键、预览条宽度和不透明度。

OrbPeek 不联网，没有账号和统计。屏幕录制权限只用于生成预览条，不录像、不录音，图像只留在内存里。
