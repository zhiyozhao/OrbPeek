OrbPeek
用法 权限 GitHub English
安装

把窗口贴到屏幕边上，
鼠标移过去就出现。

OrbPeek 是 macOS 菜单栏工具。按 ⌃⇧ 加方向键，当前窗口移出屏幕，边上只留一条预览。鼠标移到预览条上，窗口贴着这条边出现；移开，它就收回去。

安装

brew install --cask zhiyozhao/tap/orbpeek

macOS 14 或更高版本 · 免费开源 · 版本 1.1.1 · 下载 DMG

DMG 没有经过 Apple 公证，第一次打开的步骤见 README。用 Homebrew 安装不需要这一步。

主窗口不用让位

笔记、聊天、终端这类窗口，要时不时看一眼，放在旁边又挡着手头的事。OrbPeek 只动你按快捷键时最前面的那个窗口，其他窗口原样不动。

最小化

窗口进了 Dock，要回去找它、点它。

OrbPeek 的窗口就在你放它的那条边上，鼠标过去就出来，离开就收回。

分屏

两个窗口平分屏幕，主窗口要让出一部分宽度。

OrbPeek 不改主窗口的大小，另一个窗口只在你看它时盖在上面。

台前调度

重排所有窗口，屏幕一侧常驻缩略图。

OrbPeek 不改桌面布局，只动一个窗口。

预览条

窗口贴边后，屏幕边上留下的是它边缘的一张截图：贴到右边就显示窗口的左边缘，贴到上边就显示窗口的下边缘。预览条和窗口原来的位置对齐。

预览条默认宽 15 px、半透明，所以很淡；宽度和不透明度可以在设置里调。截图不会实时刷新，看过窗口、鼠标移开让它收回时，会换成新的截图。预览条只响应鼠标停留，点击会穿过它，落到下面的窗口上。

用法

贴边和换边用快捷键，其余操作用鼠标。

贴边⌃⇧ 加 ← → ↑ ↓，把当前窗口贴到左、右、上、下边。对已贴边的窗口按另一个方向，就换一条边。
查看鼠标在预览条上停一下（0.15 秒）。快速把鼠标甩到预览条上，窗口会立刻出现，不用等。
收回在窗口里停留过再移开，或者切到别的 app，窗口就收回边上。
挪位置、改大小窗口出现时，沿着这条边拖动，松手后预览条跟到新位置；改窗口大小也不会取消。
取消贴边在菜单栏图标里点这个窗口的名字，它回到贴边前的位置。也可以在它出现时往屏幕中间拖开 40 px 以上，它会留在你松手的地方。最小化这个窗口或隐藏它的 app（⌘H）也会取消贴边。

快捷键可以在设置里改。退出 OrbPeek 时，所有贴边的窗口都会回到原来的位置。

权限

菜单栏图标里能看到两项权限的状态，点没有授权的那一项就能去授权。

辅助功能必需

用来读取和移动窗口。授权后马上可用，不需要重启 OrbPeek。

屏幕录制可选

只用来截预览条：每次贴边时截一次窗口所在的区域，图片只留在内存里。不录像，不录音。不授权也能用，预览条会变成一条半透明的深色占位条。

刻意不做的事

  • 不自动贴边只有按快捷键才会贴边，把窗口拖到屏幕边上不会。
  • 不实时预览预览条是一张截图，OrbPeek 不会持续录屏。
  • 不管窗口布局不平铺、不分屏，其他窗口它不动。
  • 不联网没有账号、统计或自动上传。
